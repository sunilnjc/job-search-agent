# Job Pursuit — product verdict

**Date:** 2026-09-18  
**Status:** Locked pivot (see handoff brief).

## Verdict

Pursue Job Pursuit as a **narrow wedge**, not a broad AI career platform.

**Wedge:** ATS-direct shortlist + fact-grounded application packets for sponsorship-aware / international software candidates.

**Loop:** Discover → Rank → Prepare → Review → user applies externally.

**Not the product:** LinkedIn competitor, auto-apply engine, interview coaching product, forever SaaS subscription theater, marketplace.

## Why

- Grounded packets and eligibility honesty are differentiated for the ICP.
- Auto-apply / LinkedIn automation carry ban and ToS risk.
- Monetization before a babysit-free loop burns trust.

## Freeze vs delete

Built non-wedge code stays in the repo. Beta UI hides or demotes it. Founder dogfood tools (`/admin`, Telegram, SQLite autopilot) stay out of the multi-tenant product surface.
